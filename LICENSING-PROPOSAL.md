# Licensing proposal — not a license

This document records intent only. It does not grant permission to copy,
modify, distribute, or use the software.

## Intended direction

- make source code available for non-commercial use;
- require a separate commercial license for commercial use;
- describe the distribution as **source-available**, not open source under the
  Open Source Initiative definition;
- preserve copyright notices and transformation provenance;
- define contribution terms only after ownership and legal review.

PolyForm Noncommercial 1.0.0 is a candidate for legal review, not an adopted
license. A definitive `LICENSE` file must not be added without explicit human
approval.

## Open gates

The project owner confirmed ownership and authority for the initial public
source publication on 2026-07-26. This confirmation does not adopt a license.

1. Obtain qualified legal review of software, documentation, examples,
   contribution terms, and commercial licensing.
2. Decide how inbound contributions are licensed.
3. Complete name and trademark clearance.
4. Approve any tag, release, package publication, or definitive license.
